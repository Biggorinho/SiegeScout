# Building Hero Siege Bot as Single .EXE

## Quick Start

### Option 1: Automated Build (Recommended)
```bash
build_exe.bat
```
This creates `dist/HeroSiegeBot.exe` automatically. Done in 2-5 minutes.

### Option 2: Manual Build
```bash
pyinstaller build_exe.spec
```

## What Gets Created

- `dist/HeroSiegeBot.exe` - Standalone executable (300-400MB)
- `build/` - Build artifacts (safe to delete after)
- `HeroSiegeBot.spec` - Build configuration (autogenerated by PyInstaller)

## Distribution

The `.exe` is completely self-contained:
- ✅ No Python installation required
- ✅ No external dependencies needed
- ✅ Includes keyboard input, screen capture, CV2, all libraries
- ✅ Just copy to customer's computer and run

**File size:** ~300-400MB (this is normal for PyInstaller bundles with Python runtime)

## Customer Setup

1. Download `HeroSiegeBot.exe`
2. Run it (Windows 10/11)
3. Game window must be visible
4. Bot activates with license key

## Notes

- **First run:** May take 10-30 seconds to initialize (extracting Python runtime to temp folder)
- **Antivirus:** Some AV software flags PyInstaller .exe files (false positive). Add to whitelist if needed.
- **Windows only:** This .exe only works on Windows. For Mac/Linux, distribute as Python source instead.

## Improving the .EXE

### Add an Icon
1. Create a 256x256 .ico file
2. Edit `build_exe.spec`: `icon='path/to/icon.ico'`
3. Rebuild

### Make It Windowed (No Console)
Edit `build_exe.spec`:
```python
console=False,  # Hides console window
```

### Reduce File Size (Advanced)
Use UPX compression (optional):
```bash
pip install upx
```
It's already enabled in the spec file.

## Troubleshooting

**"ModuleNotFoundError: No module named X"**
- Add the module to `hiddenimports=[]` in build_exe.spec
- Common ones: cv2, numpy, mss, keyboard, PIL

**Antivirus quarantines .exe**
- This is a known PyInstaller issue
- Sign the .exe with a code certificate for trusted distribution
- Or distribute with `.asc` signature file

**File too large**
- 300-400MB is expected (includes full Python interpreter)
- Can't be reduced much without removing dependencies

## Version 2 Packaging

When you make Version 2:
1. Update main.py with new features
2. Update version in config.py
3. Run `build_exe.bat` again
4. Ship new `dist/HeroSiegeBot.exe`

All customers get the latest version automatically when they download the new .exe.
